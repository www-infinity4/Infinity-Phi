# Infinity Phi (∞Φ) – The Midas Touch Conundrum

Welcome to the repository for **Infinity Phi**, a psychological worldbuilding framework and simulation. This project explores the exhausting paradox of infinite survival paired with absolute geometric crystallization—inspired by the overwhelming weight of "doing everything for you" and the god-complex mechanics of unachievable perfection.

## 🌌 The Core Paradox

In the baseline universe (**Infinity**), you are given an infinite ability to survive. You can endure any environment, trauma, or epoch of time. However, you are *not* granted passive perfection. 

When you upgrade to **Infinity Phi (∞Φ)**, the Golden Ratio ($\approx 1.618$) is introduced as an absolute law of interaction. This triggers the **Midas Touch Conundrum**:

1. **Infinite Endurance:** Your core existence cannot be extinguished. 
2. **Mathematical Correction:** Because you lack innate perfection, any action you take forces the universe to correct itself.
3. **Crystallization:** Everything you touch, build, or manipulate instantly rewrites its geometry into the Golden Ratio. It becomes mathematically flawless, frozen, metallic, and entirely dead.

> *"There is no love like your love, and no other love will do... because I literally crystallized the entire sector trying to fix it for you."*

## 🛠️ System Mechanics

### 1. The Exhaustion Metric
Every action requires an exponential expenditure of energy. Because you are building a universe for a recipient who "comes back in a few hours" expecting results, the pressure to maintain structural stability while preventing total golden crystallization creates a rapid burnout loop.

### 2. The Conversion Formula
When an object $x$ is interacted with by an agent possessing $\Phi$, its molecular structure collapses into a logarithmic spiral:

$$f(n) = \Phi^n \cdot (\text{Gold Value})$$

* **Result:** Total loss of utility. Food becomes unconsumable gold geometry. Tools become rigid statues.

## 🚀 Getting Started

### Installation
Clone the paradox into your current reality matrix:
```bash
git clone https://github.com
cd infinity-phi-exhaustion
```

### Running the Simulator
To initialize the simulation and watch your environment turn into a flawless, unlivable golden prison:
```bash
python run_midas_loop.py --exhaustion-level=maximum --god-complex=true
```
